# Vibe With Aaruu — channel website

Official website for **[Vibe With Aaruu](https://www.youtube.com/@VibeWithAaruu)**, Aarushi and Harshit's YouTube channel: couple travel, Mahindra XUV 7XO diaries, festivals and everyday life from India.

**Live site:** https://harshitmodi98.github.io/vibewithaaruu/

## What's on the site
- Channel stats and the latest Himachal trip shorts
- Most-watched shorts and full-length vlogs
- Playlists / series (XUV 7XO, Himachal, Bali, iPhone surprise, Hyderabad, Indore, festivals)
- Brand collaborations and contact for collabs
- Instagram profiles

## Tech
A single static `index.html` (HTML + CSS + a little vanilla JS), hosted on GitHub Pages. No build step: edit `index.html` and push to `main`.
